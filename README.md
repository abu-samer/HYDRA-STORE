# HYDRA-STORE
Hydra Store is an academic e-commerce web project developed for the Team Project course by Ayham Jamous, Hussain Nazzal, and Islam Jarem. Built using HTML5, modern JavaScript, and Tailwind CSS, the platform delivers a vibrant and responsive online shopping experience structured across 9 core pages evenly distributed among the team members. It encompasses the complete customer journey, featuring a dynamic product catalog with search and filtering, detailed product showcases, interactive cart management, streamlined checkout, user profile authentication, and comprehensive store policies including delivery, warranty, and technical support.
